`pixel.png` é uma imagem mínima sintética usada na validação de upload.

`synthetic-video.webm` é um vídeo próprio de teste, sem dados de usuários: canvas 16×16, dez quadros alternando preto/branco, gravado por MediaRecorder em VP8/WebM. Sua única finalidade é verificar MIME, FFprobe, gravação e entrega privada de vídeo. Não é usado como mídia de demonstração do produto.
