The Vercel build compiles a minimal FFprobe from official FFmpeg 9.0.2 sources.
Source archive: https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz
SHA256: 8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e
Source, license and build configuration: tools/ffprobe-release.json and tools/vercel-build.mjs.
GPL and nonfree components are disabled. FFprobe is a separate program distributed under
GNU LGPL 2.1 or later. The build copies COPYING.LGPLv2.1 next to the executable.
No FFmpeg code is linked into the PHP application.
